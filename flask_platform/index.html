REST API Specification
Dual Response Modes

HydroFlow provides a high-throughput REST API supporting multipart file uploads, direct sample identification, and dual output modes: binary PNG mask stream (format=image) and structured telemetry (format=json).

Method Endpoint Format Description
POST /predict?format=image image/png Direct binary PNG mask stream with custom headers (X-Water-Percentage, X-Latency-Ms)
POST /predict?format=json application/json JSON payload with water %, pixel counts, latency, and base64 assets
POST /predict_geo application/json Satellite globe water segmentation with tile GPS coordinates
GET /samples application/json List verified validation scenes with metadata and ground-truth values
GET /health application/json System status, device provider, and model capability inventory
cURL • Download Binary Mask Stream
# Stream raw binary PNG mask directly to water_mask.png
curl -X POST "http://127.0.0.1:5000/predict?format=image" \
     -F "file=@sample_1_lake.tif" \
     --output water_mask.png
Python • Multipart JSON Inference
import requests

url = "http://127.0.0.1:5000/predict?format=json"
with open("sample_1_lake.tif", "rb") as f:
    res = requests.post(url, files={"file": f}, data={"threshold": 0.50})

data = res.json()
print(f"Surface Water: {data['water_percentage']}%")
print(f"Water Pixels:  {data['water_pixels']} / {data['total_pixels']}")
print(f"Latency:       {data['latency_ms']} ms")
