Task 4 Production REST API Specification

REST API Documentation & Code Snippets

HydroFlow provides a high-performance REST API strictly conforming to task 4.pdf requirements. It supports dual response modes: direct binary mask streaming (format=image) or structured telemetry and base64 visuals (format=json).

Method Endpoint Parameters Output Type Description
POST /predict?format=image file=@scene.tif image/png Returns raw binary PNG mask stream with custom HTTP headers
POST /predict?format=json file=@scene.tif, threshold=0.5 application/json Returns water %, pixels, latency, and base64 RGB/mask/overlay
POST /predict_geo { lat, lon, zoom } application/json Satellite globe water segmentation with GPS bounds
GET /samples None application/json Lists the 3 prepackaged validation scenes with metadata
GET /health None application/json Health check, device status, and model benchmark inventory

Production Integration Snippets

1. cURL — Download Binary Mask Stream (task 4.pdf requirement) 
# Download water mask directly as water_mask.png
curl -X POST "http://127.0.0.1:5000/predict?format=image" \
     -F "file=@sample_1_lake.tif" \
     --output water_mask.png
2. Python — JSON Inference with Metrics & Base64 Assets 
import requests

url = "http://127.0.0.1:5000/predict?format=json"
files = {"file": open("sample_1_lake.tif", "rb")}
data = {"threshold": 0.50}

response = requests.post(url, files=files, data=data)
result = response.json()

print(f"Water Coverage: {result['water_percentage']}%")
print(f"Water Pixels:   {result['water_pixels']} / {result['total_pixels']}")
print(f"Inference Time: {result['latency_ms']} ms")
3. Python — 1-Click Inference on Bundled Presets 
import requests

# Test prepackaged lake preset without uploading local files
res = requests.post("http://127.0.0.1:5000/predict?format=json", json={"sample_id": "sample_1_lake"})
print("Lake Sample Water %:", res.json()["water_percentage"])
