## 3. Discrepancies Between Claims and Reality

1. **Live Multispectral Earth Analysis Claim**:
   - *Claim*: "Navigate anywhere on Earth ... to query live imagery, run the segmentation model, and overlay predicted water boundaries."
   - *Reality*: The map queries 3-channel optical RGB tiles from Esri/ArcGIS. Because the model requires 12 channels, the backend cyclically tiles the RGB channels. It is NOT running on raw 12-channel Sentinel-2 surface reflectance, but an out-of-distribution optical surrogate.
2. **Simulated Fallback Telemetry**:
   - *Claim*: Displays "Detected Water: 53.5%, 8,765 px, Latency: 22 ms".
   - *Reality*: Generated via canvas `ctx.ellipse()` with no network connection and zero model inference.
3. **Hardware Acceleration Claim**:
   - *Claim*: "CPU / ONNX" badge with pulsating green light implying an active live worker.
   - *Reality*: Rendered statically in HTML without polling server state.

## 5. Re-Verification of BAND_MINS & BAND_MAXS in `config.py`

### 5.1 The Investigation
The user prompt correctly flagged that in `flask_platform/config.py`:
- Band 7 (QA_PIXEL): `min=64.0, max=224.0`
- Band 10 (ESA WorldCover): `min=10.0, max=80.0`
- Band 11 (JRC Water Occurrence): `min=0.0, max=98.0`

### 5.2 Forensic Finding in the Dataset & Training Notebooks
Forensic inspection of `notebooks/01-part1-water-segmentation-eda.ipynb` and execution across all 306 matched scenes in `satalite data/images/` revealed the scientific explanation:
- **Channels 0 to 6**: Physical Sentinel-2 optical/infrared reflectance bands (Coastal, Blue, Green, Red, NIR, SWIR-1, SWIR-2). Values range in surface reflectance units ($0 \dots 4600+$).
- **Channel 7**: **`QA_PIXEL` Bitmask layer** (cloud, shadow, and sensor validity bit flags). Values are discrete bit integers whose 99th percentile across the dataset is exactly **224.0**!
- **Channel 8 & 9**: Thermal / Auxiliary infrared layers.
- **Channel 10**: **ESA WorldCover 10m Land Use / Land Cover (LULC)** categorical classification map. The ESA WorldCover product encodes discrete class IDs:
  - 10: Tree cover
  - 20: Shrubland
  - 30: Grassland
  - 40: Cropland
  - 50: Built-up
  - 60: Bare / sparse vegetation
  - 70: Snow and ice
  - **80: Permanent water bodies**
  Because 80 represents permanent water, the 99th percentile across all samples is mathematically **80.0**!
- **Channel 11**: **JRC Global Surface Water Occurrence**, an index from 0 to 100 representing historical water frequency percentage. Hence, its 99th percentile is **98.0 to 99.0**!

### 5.3 Reporting to User
In `config.py`, the band labels currently describe standard 12 optical bands (`B1` to `B12`), whereas the actual raster channels in this dataset contain these auxiliary GIS layers (`QA_PIXEL`, `ESA WorldCover`, `JRC Occurrence`). **The numeric bounds `[64, ..., 224]` and `[10, ..., 80]` are mathematically correct for this specific dataset**, but the text descriptions in `config.py` were mislabeled! We will update the metadata labels in `config.py` to reflect their true physical meaning.

## 6. Esri World Imagery Attribution & Usage Compliance

The interactive map utilizes tiles from:
`https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}`

Per Esri Terms of Use:
- Proper attribution must remain visible on the map viewport.
- Required attribution string:
  `Tiles &copy; Esri &mdash; Source: Esri, i-cubed, USDA, USGS, AEX, GeoEye, Getmapping, Aerogrid, IGN, IGP, UPR-EGP, and the GIS User Community`
- In addition, the UI must explicitly notify users that optical satellite basemaps are provided for contextual exploration and are processed through an experimental RGB-adapted pipeline.
