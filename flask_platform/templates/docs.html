Task 4 Production API

HydroFlow exposes high-throughput endpoints for multispectral Sentinel-2 water segmentation. Designed to meet the requirements of task 4.pdf, supporting dual outputs: raw binary mask stream (format=image) and rich analytical payload (format=json).

POST

/predict

Executes deep learning inference on an uploaded multispectral GeoTIFF or preset sample scene. Returns either a binary PNG mask or full JSON telemetry.

Parameter Type Default Description
format query json image returns PNG binary stream; json returns metrics and base64 assets
threshold query/form 0.50 Sigmoid decision threshold in range [0.01, 0.99]
file multipart none Uploaded raster payload (.tif / .png / .jpg) up to 32 MB
sample_id query/json none Identifier for prepackaged scenes (sample_1_lake, sample_2_river, sample_3_stream)
cURL • Download Binary Mask Stream (task 4.pdf requirement)
curl -X POST "http://localhost:5000/predict?format=image" \
  -F "file=@sample_1_lake.tif" \
  -F "threshold=0.50" \
  --output water_mask.png
Python requests • JSON Inference with Telemetry
import requests

url = "http://localhost:5000/predict?format=json"
with open("sample_1_lake.tif", "rb") as f:
    resp = requests.post(url, files={"file": f}, data={"threshold": 0.50})

result = resp.json()
print("Water Coverage:", result["water_percentage"], "%")
print("Water Pixels:  ", result["water_pixels"], "/", result["total_pixels"])
POST

/predict_geo

Fetches satellite imagery for specified GPS coordinates and returns predicted water contour with geospatial bounds. 

curl -X POST "http://localhost:5000/predict_geo" \
  -H "Content-Type: application/json" \
  -d '{"lat": 22.45, "lon": 31.85, "zoom": 12, "threshold": 0.50, "area_mode": "small"}'
GET

/samples

Lists prepackaged validation scenes with metadata.

curl http://localhost:5000/samples
GET

/health

Returns model device, ONNX status, and benchmark inventory.

curl http://localhost:5000/health
