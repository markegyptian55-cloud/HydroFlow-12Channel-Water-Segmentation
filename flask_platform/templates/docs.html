HydroFlow Water Intelligence API Specification

HydroFlow exposes high-throughput endpoints for multispectral Sentinel-2 water segmentation. Designed to meet the requirements of task 4.pdf, supporting dual outputs: raw binary mask stream (format=image) and rich analytical payload (format=json).

POST

/predict

Executes deep learning inference on an uploaded multispectral GeoTIFF or preset sample scene. Returns either a binary PNG mask or full JSON telemetry.

Query & Form Parameters

Parameter Type Required Default Description
format string No json image returns PNG binary stream; json returns metrics & base64
threshold float No 0.50 Sigmoid decision threshold in range [0.01, 0.99]
file binary Conditional None Multipart file payload (.tif / .png / .jpg)
sample_id string Conditional None Direct identifier for bundled presets (sample_1_lake, sample_2_river, sample_3_stream)
cURL (Binary PNG Mask Download) 
curl -X POST "http://localhost:5000/predict?format=image" \
  -F "file=@sample_1_lake.tif" \
  -F "threshold=0.5" \
  --output water_mask.png
Python requests (JSON Telemetry) 
import requests

url = "http://localhost:5000/predict?format=json"
files = {"file": open("sample_1_lake.tif", "rb")}
resp = requests.post(url, files=files)
print(resp.json())
POST

/predict_geo

Accepts GPS coordinates and zoom level, fetches live optical satellite imagery tile, executes water segmentation, and returns an alpha mask overlay with exact bounds for Leaflet ImageOverlay. 

curl -X POST "http://localhost:5000/predict_geo" \
  -H "Content-Type: application/json" \
  -d '{"lat": 23.97, "lon": 32.88, "zoom": 13, "threshold": 0.5}'
GET

/samples

Returns metadata, ground truth values, and asset paths for all 3 bundled validation scenes. 

curl http://localhost:5000/samples
GET

/health

Returns service health, loaded PyTorch device, backbone parameters, and global benchmark IoU metrics. 

curl http://localhost:5000/health
